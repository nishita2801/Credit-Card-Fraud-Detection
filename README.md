# Credit Card Fraud Detection Dashboard

An interactive Streamlit dashboard for comparing machine learning models that classify credit card transactions as legitimate or fraudulent.

## Dashboard features

- Dataset overview with transaction and class counts
- Model comparison using precision, recall, F1-score, and ROC-AUC
- Individual model performance cards
- Confusion matrix heatmap for the selected model
- ROC curve comparison
- Business analysis to help interpret model performance

## Requirements

- Python
- Packages listed in `requirements.txt`
- Credit card dataset at `data/raw/creditcard.csv`
- Evaluation files generated by `src.evaluate`

## Setup

Open a terminal in the project folder and run:

    py -m venv .venv
    .\.venv\Scripts\Activate.ps1
    py -m pip install -r requirements.txt

If you have not generated the evaluation files yet, run:

    py -m src.evaluate

## Run the dashboard

In the project folder, run:

    streamlit run app.py

Streamlit will show a local address in the terminal and open the dashboard in your browser.

## Custom theme

The app loads its styling from:

    assets/dashboard.css

If this file is missing, the dashboard can still run, but the custom theme will not appear.
